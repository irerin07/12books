# 댓글 수 저장 제거

댓글 수는 `comments`에서 삭제·숨김되지 않았고 작성자가 탈퇴하지 않은 행의 개수다.
게시글 상세·목록 조회 projection에서 이 개수를 함께 읽는다. 응답의 `commentCount`는 유지한다.
댓글 작성·삭제, 신고 처리, 회원탈퇴는 더 이상 게시글의 댓글 수를 갱신하지 않는다.
좋아요 카운터는 이번 변경 범위가 아니므로 유지한다.

## 배포

V14는 `posts.comment_count`와 이를 참조하는 CHECK를 제거하고 좋아요 수 CHECK는 유지한다.
댓글 원본 행은 삭제하지 않는다. 기존 Flyway 마이그레이션은 수정하지 않는다.

구버전은 제거될 컬럼을 읽고 쓰므로 **구버전 인스턴스를 모두 종료한 뒤 신버전을 시작해야 한다.**
구버전과 신버전이 겹치는 롤링 배포에는 사용할 수 없다. 배포 전 DB 백업을 확보한다.
구버전으로 되돌리려면 컬럼과 제약을 복원하고 공개 댓글 기준으로 재집계해야 한다.
이 변경에서 실제 개발·운영 DB에 마이그레이션을 실행하지는 않는다.

## 검증

Docker 엔진이 실행 중인 환경에서 `./gradlew test`를 실행한다.
알림의 탈퇴 행위자 생략, 동시 댓글 작성·삭제·신고, 탈퇴와 운영자 복구,
게시글 상세·피드의 응답 집계 및 Flyway 적용을 통합 테스트로 확인한다.
집계는 기존 댓글의 게시글 ID 인덱스를 활용할 수 있으나, 대용량 실측은 별도로 필요하다.
